# MainCrafts Landing Page

A modern, responsive, and visually appealing landing page designed for MainCrafts, a fictional digital solutions and web services brand. This project was developed as part of a Full Stack Web Development Internship to demonstrate strong fundamentals of front-end development, responsive web design, and user interface creation using HTML, CSS, and JavaScript.

The website focuses on delivering a clean user experience through modern design principles, smooth interactions, responsive layouts, and structured content sections. It is optimized to work seamlessly across desktops, tablets, and mobile devices.

---

## Project Overview

MainCrafts Landing Page is a single-page responsive website that showcases a professional business presence through:

* A modern navigation system with dropdown functionality
* A visually engaging hero section
* Interactive feature cards with hover effects
* Clean typography and color palette
* Fully responsive layouts for multiple screen sizes
* Professional footer section with important links

The project emphasizes simplicity, usability, and modern UI/UX practices while maintaining a polished and professional appearance.
