# MainCrafts Landing Page

A modern, responsive, and visually appealing landing page built using HTML, CSS, and JavaScript. The project was developed as part of a Full Stack Web Development Internship to demonstrate front-end development skills, responsive design principles, and modern user interface creation.

The website is designed for a fictional digital solutions company called **MainCrafts** and showcases a professional landing page with a clean layout, engaging visuals, and responsive functionality across all devices.

---

## Project Overview

The MainCrafts Landing Page serves as a modern business website that highlights digital services and features through an intuitive user interface. The project focuses on providing an engaging user experience while maintaining a clean and professional design.

Key objectives of this project include:

* Building a responsive landing page
* Implementing a navigation bar with dropdown functionality
* Creating a visually appealing hero section
* Showcasing business features through interactive cards
* Applying modern styling techniques and hover effects
* Ensuring compatibility across desktop, tablet, and mobile devices

---
